Default clip settings

Video-aware narration

Checking local video-analysis configuration…

Install the optional local Ollama vision model moondream to analyze sampled frames from each scene. No images are uploaded to ElevenLabs. Stills cannot establish movement between frames, and AI commentary requires human review.

YouTube URL imports

Checking authorized YouTube import configuration…

Optional: securely mount a YouTube-only Netscape cookies.txt file at ./private-auth/youtube.txt on your Docker host. The file remains outside Git and is not uploaded through the browser. Use only with videos you have permission to download and edit.

If account verification keeps failing, import the original MP4 directly instead. Session cookies do not guarantee access.

AI processing

Checking Ollama configuration…

AI runs inside your private Docker network. For slower servers, reduce clips per job or choose Audio-energy mode.

Commentator voice

Checking voice connection…

ElevenLabs voiceover requires CLIPFORGE_ELEVENLABS_API_KEY and CLIPFORGE_ELEVENLABS_VOICE_ID in your server's .env. Only generated script text is sent to the voice provider. API usage may incur charges.

Publishing connections

Configure platform credentials in your server's private .env. Publishing is always manually approved.

Security & storage

ClipForge is a private, single-user preview with no built-in login. Keep Tailscale access limited to trusted devices. Docker volumes preserve existing clips and resumable checkpoints.
