Commentator voice

Checking voice connection…

ElevenLabs voiceover requires CLIPFORGE_ELEVENLABS_API_KEY and CLIPFORGE_ELEVENLABS_VOICE_ID in your server's .env. Only generated script text is sent to the voice provider. API usage may incur charges.

Publishing connections

Configure platform credentials in your server's private .env. Publishing is always manually approved.

Security & storage

ClipForge is a private, single-user preview with no built-in login. Keep Tailscale access limited to trusted devices. Docker volumes preserve existing clips and resumable checkpoints.
